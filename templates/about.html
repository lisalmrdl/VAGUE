V.A.G.U.E.

Thanks for trying out V.A.G.U.E.!

This search engine was developed as part of the Building NLP Applications course at the University of Helsinki.

Our goal was to understand the usage of NLP and information retrieval strategies by implementing a simple search engine. It allows the user to search a database of almost 10.000 games using exact titles, genres, keywords, or similarity-based queries.

As retrieval strategies we used Boolean serach, TF-IDF, and neural search. Then we built an easy accessible web interface around it to facilitate the usage. We also used data visualization and user experience (UX) design techniques to make the website more accessible and engaging.

The project was implemented in Python and relies on libraries such as Pandas, NumPy, Flask, Matplotlib, sqlite3, Sentence Transformers, and scikit-learn.
